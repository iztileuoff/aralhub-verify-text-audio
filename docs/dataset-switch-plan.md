⚠️ **Партия пришла без строки заголовков** — её вырезали из общего файла, и шапка не
повторилась. FastExcel принимает за шапку первую строку данных, поэтому колонки `text`

пересобрали и залили 201 строку целиком. Теперь такой файл `import:excel-file`
**отклоняет** с подсказкой про заголовки. Проверять любую новую партию до заливки:
у первой строки должны быть имена колонок, а не `kaa-00xxxx`.
