# ТЗ для фронта: обрезка и расшифровка телефонных звонков

## Контекст

Заказчик передал ≈ 8 ГБ записей телефонных разговоров **без текста**; каждый звонок
**не длиннее 2 минут**. Для них заводится
отдельный раздел и новая роль — **обрезчик** (5 аккаунтов). Обрезчик:

1. получает звонок из общей очереди;
2. отрезает начало до разговора (гудки, автоответчик, тишину) и тишину в конце;
3. пишет **весь разговор одним текстом** на каракалпакской **латинице**;
4. сохраняет — результат уходит на модерацию.

Модератор (админ) слушает, при необходимости правит текст и **принимает** или **возвращает**
звонок обрезчику с причиной. Админ видит статистику: сколько сделано, кем, сколько минут.

Один звонок = **одна** обрезка с **одним** общим текстом. Резать звонок на куски не нужно.

Основа экрана обрезки — готовый прототип `audio-kesgich.html` (waveform, выделение,
«оставить выделенное», undo, экспорт WAV). Ниже — что в нём поменять и как связать с API.

## Базовое

- **Base URL:** `/api/v1/admin`
- **Авторизация:** `Authorization: Bearer <token>` (Sanctum), как в остальной админке
- **Заголовок:** `Accept: application/json`
- **Роль обрезчика:** `role = 6` (приходит в `user.role` при логине и в `GET profile`)

## ⚠️ Главные правила

- **Результат — WAV, 16 000 Hz, mono, 16-bit PCM.** Сервер читает заголовок файла и
  отклоняет всё остальное (`422`).
- **Длительность обрезанного аудио считает сервер** по самому файлу, в **сэмплах при 16 kHz**
  (`секунды = trimmed_duration / 16000`), как во всём проекте. Фронт её не присылает.
- **Точки обрезки и длительность исходника — в миллисекундах** относительно **исходного**
  файла: у исходников своя частота (телефонные бывают 8 kHz), сэмплы там не годятся.
- **Текст — только каракалпакская латиница.** Кириллица запрещена, числа можно цифрами (см. «Правила текста»).

## Роли и меню

| Роль | Что видит |
|------|-----------|
| Обрезчик (`role = 6`) | **Только** «Работа» и «Моя статистика». Никаких других разделов админки. |
| Админ / супер-админ | Всё, что сейчас, плюс «Звонки — модерация» и «Звонки — статистика». |

Бэкенд тоже закрывает обрезчику все остальные эндпоинты (`403`), но меню должно быть скрыто
и на фронте.

Аккаунты обрезчиков создаются через существующий экран пользователей
(`POST /api/v1/admin/users`) с `role = 6` — роль появится в `GET /api/v1/admin/roles`.

## Статусы звонка `status`

| Статус | Смысл | Где виден |
|--------|-------|-----------|
| `pending` | в очереди, никто не взял | статистика |
| `in_progress` | взят обрезчиком, он работает | статистика |
| `submitted` | сдан, ждёт модерации | модерация, «Моя статистика» |
| `approved` | принят модератором | модерация (`status=approved`), статистика |
| `rejected` | возвращён обрезчику с причиной | у обрезчика — первым в очереди |
| `skipped` | обрезчик пометил как непригодный | модерация (`status=skipped`) |

## Ресурс звонка (`Call`)

Один и тот же объект приходит во всех ответах ниже.

```json
{
  "id": 1532,
  "original_filename": "2026-09-14_10-22-31_998901234567.mp3",
  "source_url": "https://…r2.cloudflarestorage.com/…?X-Amz-Signature=…",
  "source_url_expires_at": "2026-10-24T15:40:00+05:00",
  "source_duration_ms": 184320,
  "trimmed_url": "https://…?X-Amz-Signature=…",
  "trim_start_ms": 7450,
  "trim_end_ms": 179900,
  "trimmed_duration": 2759200,
  "trimmed_duration_seconds": 172.45,
  "transcript": "Assalawma áleykum, Aralhub operatorı tıńlap tur…",
  "status": "submitted",
  "reject_reason": null,
  "rejections_count": 0,
  "skip_reason": null,
  "skip_comment": null,
  "trimmer": { "id": 41, "first_name": "Ayjan", "last_name": "…" },
  "submitted_at": "2026-10-24T14:31:02+05:00",
  "moderator": null,
  "moderated_at": null
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | int | id звонка |
| `original_filename` | string | имя файла для отображения: **обрезчику** — нейтральное (`call-000123.mp3`), **админу** — исходное имя заказчика (в нём номер звонящего и имя оператора) |
| `source_url` | string | **временная** ссылка на исходник; живёт ≈ 60 мин, см. `source_url_expires_at` |
| `source_duration_ms` | int\|null | длительность исходника; `null`, пока звонок ни разу не сдавали |
| `trimmed_url` | string\|null | временная ссылка на обрезанный WAV; `null`, пока не сдан |
| `trim_start_ms` / `trim_end_ms` | int\|null | где отрезано, мс от начала **исходника** |
| `trimmed_duration` | int\|null | длительность результата **в сэмплах** (16 kHz) |
| `trimmed_duration_seconds` | float\|null | `trimmed_duration / 16000` |
| `transcript` | string\|null | текст разговора |
| `status` | string | см. таблицу статусов |
| `reject_reason` | string\|null | причина последнего возврата — **показывать обрезчику крупно** |
| `rejections_count` | int | сколько раз звонок возвращали |
| `skip_reason` / `skip_comment` | string\|null | почему помечен непригодным |
| `trimmer` / `moderator` | object\|null | кто обрезал / кто модерировал |

Ссылки временные, потому что это разговоры реальных людей и бакет закрыт. Если ссылка
протухла (плеер получил `403` от хранилища) — заново запросить звонок (`GET calls/current`).

## Часть 1. Обрезчик

### 1.1. Взять звонок

```
GET /api/v1/admin/calls/current
```

Отдаёт звонок, над которым обрезчик **сейчас** работает. Если такого нет — бронирует
следующий. Порядок:

1. свой звонок `in_progress` (после перезагрузки страницы вернётся тот же);
2. свой **возвращённый** (`rejected`) — с `reject_reason`, текстом и точками обрезки прошлой
   попытки, чтобы исправить, а не делать заново;
3. новый из очереди.

**`200`:** `{ "data": Call }` — при этом статус становится `in_progress`.

**`200` с `{ "data": null }`** — очередь пуста. Показать «Звонков больше нет».

Бронь держится **30 минут** без сдачи — потом звонок возвращается в очередь и может уйти
другому. Повторный `GET calls/current` не продлевает бронь, продлевает только сдача.

### 1.2. Сдать звонок

```
POST /api/v1/admin/calls/{call}/submit
Content-Type: multipart/form-data
```

| Поле | Тип | Обяз. | Правила |
|------|-----|-------|---------|
| `audio` | file | да | WAV 16 kHz / mono / 16-bit PCM; до 10 МБ, не длиннее 3 минут (2 мин ≈ 3.8 МБ) |
| `transcript` | string | да | правила текста ниже; от 2 символов |
| `trim_start_ms` | int | да | `≥ 0` |
| `trim_end_ms` | int | да | `> trim_start_ms`, `≤ source_duration_ms` |
| `source_duration_ms` | int | да | длительность **исходника** в мс (`buffer.duration * 1000`, округлить) |

**`201`:** `{ "data": Call }` со статусом `submitted`. Сразу запросить следующий
(`GET calls/current`).

**Ошибки:**

| Код | Когда | Тело |
|-----|-------|------|
| `422` | валидация: не тот формат WAV, кириллица в тексте, неверные мс | `{ "message": "...", "errors": { "audio": ["Нужен WAV 16 kHz mono 16-bit, получен 44100 Hz stereo."] } }` |
| `409` | звонок уже не ваш (бронь истекла и его взял другой) или уже сдан | `{ "message": "Этот звонок больше не закреплён за вами." }` |
| `503` | сбой хранилища, можно повторить | `{ "message": "Не удалось сохранить аудио. Попробуйте ещё раз." }` |

Повторная отправка после таймаута безопасна: если звонок уже сдан этим же обрезчиком,
сервер ответит `201` с сохранённым состоянием, а не `409`.

### 1.3. Пометить как непригодный

```
POST /api/v1/admin/calls/{call}/skip
Content-Type: application/json
```

| Поле | Тип | Обяз. | Значения |
|------|-----|-------|----------|
| `reason` | string | да | `no_speech` (нет разговора), `broken` (битый/не открывается), `not_karakalpak` (другой язык), `unintelligible` (ничего не разобрать), `other` |
| `comment` | string | при `other` | до 500 символов |

**`200`:** `{ "data": Call }` со статусом `skipped`. Админ увидит его в модерации и может
вернуть в очередь.

Если `decodeAudioData` не смог открыть файл — предложить обрезчику `skip` с `broken`.

### 1.4. Вернуть в очередь, не делая

```
POST /api/v1/admin/calls/{call}/release
```

Без тела. Для «конец смены, не успел». **`200`:** `{ "message": "Звонок возвращён в очередь." }`.
Возвращённый модератором (`rejected`) так отпустить нельзя — `422`, его надо исправить.

### 1.5. Моя статистика

```
GET /api/v1/admin/calls/my/stats?date=2026-10-24
```

`date` — необязательный, по умолчанию сегодня.

```json
{
  "data": {
    "date": "2026-10-24",
    "day":   { "submitted": 14, "approved": 9, "rejected": 1, "skipped": 2, "trimmed_duration_seconds": 2710.5 },
    "total": { "submitted": 212, "approved": 180, "rejected": 11, "skipped": 17, "on_moderation": 21,
               "approved_duration_seconds": 35120.0 }
  }
}
```

### 1.6. Мои работы

```
GET /api/v1/admin/calls/my?status=submitted&per_page=20&page=1
```

`status` — необязательный: `submitted` / `approved` / `rejected` / `skipped`. Пагинация
Laravel, элементы — `Call`. Только просмотр: исправлять можно только то, что пришло через
`calls/current`.

## Экран «Работа» (на основе `audio-kesgich.html`)

### Что убрать из прототипа

- Загрузку файлов с диска (drag&drop, `<input type=file>`) и список файлов слева — звонок
  приходит с сервера, по одному.
- Кнопку **«O'rtasini kesish»** (удалить середину) и клавишу `Delete`: режем **только начало
  и конец**, иначе `trim_start_ms`/`trim_end_ms` перестанут описывать результат.
- Выбор формата/каналов/частоты/битрейта и M4A-экспорт — параметры фиксированы.
- **Нормализацию громкости** (`Normalize`) — сигнал не трогаем, сохраняем как есть.
- Кнопки «Скачать».

### Что оставить

Waveform, выделение мышью, перетаскивание краёв, поля «Boshi/Oxiri», проигрывание всего и
выделенного, **«Faqat tanlanganni qoldirish»** (оставить выделенное), undo, «Aslini qaytarish»,
горячие клавиши `Space`, `K`, `Ctrl+Z`.

### Что добавить

- Над waveform: `original_filename`, длительность, и если `rejections_count > 0` — **красная
  плашка** с `reject_reason`.
- Под waveform: большое поле текста (многострочное) и панель кнопок-букв
  **á ǵ ı ń ó ú / Á Ǵ Í Ń Ó Ú** — вставляют символ в позицию курсора (на обычной
  клавиатуре их нет).
- Подсветка ошибок текста **до** отправки (те же правила, что проверит сервер).
- Кнопки: **«Saqlaw»** (сдать), **«Jaramsız»** (skip, с выбором причины), «Keyin» (release).
- Черновик текста сохранять в `localStorage` по ключу `call-draft-<id>` и восстанавливать,
  чтобы перезагрузка страницы не стирала работу. Очищать после успешной сдачи.
- Горячая клавиша `Ctrl+Enter` — сдать.

### Загрузка исходника

```js
const ctx = new AudioContext({ sampleRate: 16000 });   // сразу 16 kHz
const res = await fetch(call.source_url);             // бакет отдаёт CORS для домена админки
const buf = await ctx.decodeAudioData(await res.arrayBuffer());
```

`AudioContext({ sampleRate: 16000 })` — чтобы `decodeAudioData` сразу ресемплировал в
итоговую частоту: waveform, проигрывание и экспорт работают с тем же звуком, что уйдёт на
сервер. Звонки не длиннее 2 минут, так что по памяти ограничений нет.
`source_duration_ms = Math.round(buf.duration * 1000)` — это длительность исходника.

### Точки обрезки

«Оставить выделенное» можно нажимать несколько раз, поэтому храните смещение от начала
исходника:

```js
// при каждом keep(): offsetMs += sel[0] * 1000
trim_start_ms = Math.round(offsetMs);
trim_end_ms   = Math.round(offsetMs + current.duration * 1000);
// undo / reset откатывают offsetMs вместе с буфером
```

Если обрезчик ничего не отрезал — `trim_start_ms = 0`, `trim_end_ms = source_duration_ms`.

### Сохранение в WAV 16 kHz mono

```js
const oc = new OfflineAudioContext(1, Math.ceil(current.duration * 16000), 16000);
const s = oc.createBufferSource(); s.buffer = current; s.connect(oc.destination); s.start();
const mono = await oc.startRendering();   // стерео (оператор/клиент) сводится в mono
const wav = toWav(mono);                  // функция из прототипа: 16-bit PCM
```

`toWav` из прототипа подходит без изменений. Имя файла в `FormData` любое — сервер даст своё.

## Правила текста

- **Алфавит — каракалпакская латиница:** `A–Z a–z` и `Á á Ǵ ǵ Í ı Ń ń Ó ó Ú ú`.
  Пара к заглавной `Í` — строчная **`ı`** (без точки). Если ввели `í`, сервер сам заменит на `ı`.
- Сервер сам приводит типографские кавычки (`’ ‘ “ ” « »`) к обычным, а переносы строк и
  двойные пробелы — к одному пробелу: текст хранится одной строкой.
- **Кириллица запрещена** — любая буква `А–я, Ўў, Ққ, Ғғ, Ңң, Өө, Үү, Ҳҳ` → ошибка.
- **Числа — как удобно:** цифрами (`15`) или словами (`on bes`).
- Разрешённая пунктуация: пробел, `. , ? ! - ' " : ;`.
- Пишется **весь разговор** обеих сторон, подряд, без пометок «оператор:» / «клиент:» и без
  `[шум]`, `[смех]`.
- Неразборчивое место пропустить; если разобрать нельзя почти ничего — `skip` с
  `unintelligible`.

Подсветка на фронте: регулярка для запрещённого —
`/[^A-Za-zÁáǴǵÍıŃńÓóÚú0-9 \.,\?!\-'":;\n]/u` → подчеркнуть найденные символы.

## Часть 2. Модерация (админ)

### 2.1. Список

```
GET /api/v1/admin/calls/moderation?status=submitted&trimmer_id=41&per_page=20&direction=asc&page=1
```

| Параметр | По умолчанию | Примечание |
|----------|--------------|------------|
| `status` | `submitted` | `submitted` / `approved` / `rejected` / `skipped` |
| `trimmer_id` | — | фильтр по обрезчику |
| `per_page` | 20 | макс. 100 |
| `direction` | `asc` | по `submitted_at` |

Пагинация Laravel, элементы — `Call`.

**Экран:** два плеера — исходник (`source_url`) и результат (`trimmed_url`); на waveform
исходника отметить `trim_start_ms`/`trim_end_ms`, чтобы было видно, не отрезано ли лишнее.
Текст — в редактируемом поле. Кнопки «Принять» и «Вернуть».

### 2.2. Принять

```
POST /api/v1/admin/calls/{call}/approve
Content-Type: application/json
```

| Поле | Тип | Обяз. | Примечание |
|------|-----|-------|------------|
| `transcript` | string | нет | исправленный текст, если модератор поправил опечатки; те же правила |

**`200`:** `{ "data": Call }` со статусом `approved`. `422` — если звонок не в `submitted`.

### 2.3. Вернуть обрезчику

```
POST /api/v1/admin/calls/{call}/reject
Content-Type: application/json
```

| Поле | Тип | Обяз. | Примечание |
|------|-----|-------|------------|
| `reason` | string | да | что исправить; до 500 символов — обрезчик увидит это крупно |

**`200`:** `{ "data": Call }` со статусом `rejected`. Звонок вернётся **тому же** обрезчику
первым в очереди.

### 2.4. Вернуть непригодный в очередь

```
POST /api/v1/admin/calls/{call}/restore
```

Только для `skipped` (если обрезчик ошибся). Звонок уходит в `pending`. **`200`:** `{ "data": Call }`.

## Часть 3. Статистика (админ)

```
GET /api/v1/admin/calls/stats?from=2026-10-01&to=2026-10-31
```

`from` / `to` — необязательные, по умолчанию сегодня. Влияют только на блок `trimmers`
(события за период); `totals` — всегда текущее состояние всей очереди.

```json
{
  "data": {
    "period": { "from": "2026-10-01", "to": "2026-10-31" },
    "totals": {
      "files_total": 4120,
      "pending": 3010, "in_progress": 5, "submitted": 61,
      "approved": 940, "rejected": 12, "skipped": 92,
      "approved_duration_seconds": 162400.0,
      "exported": 800
    },
    "trimmers": [
      {
        "user": { "id": 41, "first_name": "Ayjan", "last_name": "…" },
        "submitted": 212, "approved": 180, "rejected": 11, "skipped": 17,
        "trimmed_duration_seconds": 40210.5,
        "approved_duration_seconds": 35120.0,
        "last_activity_at": "2026-10-24T14:31:02+05:00"
      }
    ]
  }
}
```

| Поле в `trimmers[]` | Что считает за период |
|---------------------|-----------------------|
| `submitted` | сдачи, включая повторные после возврата |
| `approved` | звонки этого обрезчика, принятые модератором |
| `rejected` | возвраты (один звонок, возвращённый дважды, = 2) |
| `skipped` | помеченные непригодными |
| `trimmed_duration_seconds` | минуты результата по сдачам |
| `approved_duration_seconds` | минуты результата по принятым — **главная цифра оплаты/плана** |

**Экран:** сверху плашки `totals` и прогресс-бар `(approved + skipped) / files_total`;
ниже таблица обрезчиков с сортировкой; показывать секунды как `ч:мм`. Полезно показать
долю возвратов `rejected / submitted` — это качество работы.

## Пользовательский сценарий обрезчика

1. Вход → роль `6` → сразу экран «Работа».
2. `GET calls/current` → загрузить исходник, показать waveform (и причину возврата, если есть).
3. Прослушать, выделить от начала разговора до конца, «оставить выделенное».
4. Написать текст (кнопки-буквы, подсветка ошибок).
5. «Saqlaw» → `POST calls/{id}/submit` → сразу следующий звонок.
6. Если звонок пустой/битый/не на каракалпакском → «Jaramsız» → `POST calls/{id}/skip`.
7. В конце смены — «Keyin» → `POST calls/{id}/release`.

## Бэкенд-нюансы (не блокируют фронт)

- Звонки и их результаты живут **отдельно** от основного датасета (`texts`/`audio`): они не
  попадают в существующие очереди, счётчики и отчёты.
- Бакет с исходниками приватный; CORS для домена админки настраивается на бэкенде. Если
  `fetch(source_url)` падает с CORS-ошибкой — сообщить бэкенду домен фронта.
- Принятые звонки выгружаются в `.tsv` artisan-командой — на фронте экрана экспорта нет.
