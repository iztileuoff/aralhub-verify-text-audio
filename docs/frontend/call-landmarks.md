# Ориентиры в звонках — экран для админов (27.10.2026)

> **Статус: бэкенд на проде.** Нужен фронт: один экран и один пункт меню у админа.

Для фронтенд-разработчика админки `https://dataset.aralhub.uz`. Продолжение раздела звонков
(`docs/frontend/call-trim.md`): стек, авторизация и объект звонка `Call` — те же.

## Зачем

Звонящие называют **ориентиры** — места, куда или откуда ехать (`Yurfak`, `Aeroport`, `Bayu bazar`…).
Нужен **словарь ориентиров**, и на каждый — **одно аудио**, где его произносят. Размечают админы:

1. Админ получает **случайный** обрезанный звонок (из сданных и принятых) и слушает его.
2. Пишет **одно слово-ориентир**. Пока он печатает (`Yu…`), под полем — подсказки из уже
   существующих ориентиров.
3. Ориентира ещё нет → **«Saqlaw»**: создаётся ориентир, этот звонок — его аудио.
4. Ориентир **уже есть** (`Yurfak` в подсказках) → звонок **пропускается** («Ótkerip jiberiw»):
   аудио для `Yurfak` уже собрано. Если хочется оставить и этот звонок как ещё один пример —
   **«Bul da Yurfak»**.
5. В разговоре нет ориентира → **«Orientir joq»**.
6. После любого решения — сразу следующий звонок. **Звонок с решением больше никогда не показывается.**

## Меню

Админу и супер-админу — новый пункт **«Qońırawlar — orientirler»** (рядом с модерацией и
статистикой звонков). Обрезчику — не показывать (бэкенд ответит `403`).

## Базовое

- **Base URL:** `https://api.verify.aralhub.uz/api/v1/admin`
- **Авторизация:** `Authorization: Bearer <token>`, `Accept: application/json` — как везде.
- Объект `Call` — как в `call-trim.md`; админу в нём дополнительно приходят:

| Поле | Тип | Описание |
|------|-----|----------|
| `landmark_decision` | string\|null | `primary` (новый ориентир) / `also` (ещё пример) / `duplicate` (пропущен, ориентир уже был) / `none` (ориентира нет) / `null` (ещё не размечен) |
| `landmark` | object\|null | `{id, name}` — с каким ориентиром связан звонок |

### Объект ориентира `Landmark`

```json
{
  "id": 12,
  "name": "Yurfak",
  "examples_count": 2,
  "mentions_count": 17,
  "primary_call": {
    "id": 4810,
    "trimmed_url": "https://…?X-Amz-Signature=…",
    "trimmed_duration_seconds": 11.4,
    "transcript": "Assalawma áleykum, Yurfakqa mashına kerek…"
  },
  "created_by": {"id": 2, "first_name": "…", "last_name": "…"},
  "created_at": "2026-10-27T10:15:00+00:00"
}
```

| Поле | Описание |
|------|----------|
| `examples_count` | сколько звонков сохранено как аудио ориентира (главный + «Bul da …») |
| `mentions_count` | сколько всего звонков с ним размечено, включая пропущенные — насколько ориентир частый |
| `primary_call` | главное аудио; `trimmed_url` — временная ссылка (≈ 60 мин) |

## 1. Следующий звонок — `GET /calls/landmarks/current`

Отдаёт звонок, который этот админ уже держит (перезагрузка вернёт тот же), иначе бронирует
**случайный** свободный. Бронь — 30 минут; двое админов один звонок не получат.

```json
{
  "data": { …Call… },
  "meta": { "remaining": 9431, "landmarks_total": 127 }
}
```

- `data: null` — размечать нечего (показать «Hámmesi belgilendi»).
- `meta.remaining` — сколько звонков ещё без решения; `meta.landmarks_total` — размер словаря.
  Показывать над плеером.
- Проигрывать `data.trimmed_url` (обрезанный результат). Показать `data.transcript` — по тексту
  ориентир часто видно быстрее, чем на слух.

## 2. Подсказки и словарь — `GET /calls/landmarks?search=yu&per_page=10`

| Параметр | Описание |
|----------|----------|
| `search` | что набрано; без учёта регистра; сначала ориентиры, **начинающиеся** с набранного, потом **содержащие** его |
| `per_page` | для подсказок — 8–10; для страницы словаря — 20–50 (макс. 100) |

Пагинация Laravel, элементы — `Landmark`. Без `search` — весь словарь по алфавиту (можно сделать
отдельную вкладку «Sózlik» со списком, поиском и проигрыванием `primary_call`).

Подсказки: запрос с задержкой ~200 мс после ввода, от 1 символа.

## 3. Решение по звонку — `POST /calls/{id}/landmark`

| `decision` | Ещё поля | Когда |
|------------|----------|-------|
| `primary` | `name` — ориентир (латиница, до 100 символов) | новый ориентир |
| `duplicate` | `landmark_id` — из подсказки | ориентир уже есть — пропустить звонок |
| `also` | `landmark_id` — из подсказки | ориентир уже есть — оставить как ещё пример |
| `none` | — | ориентира в разговоре нет |

**`200`:** `{ "data": Call, "landmark": Landmark | null }` → сразу `GET /calls/landmarks/current`.

| Код | Когда | Что делать |
|-----|-------|-----------|
| `409` + `landmark` | `primary`, но такой ориентир уже есть (`"yurfak"`, `" Yurfak."` — тот же) | показать «Yurfak уже есть» и две кнопки: «Ótkerip jiberiw» (`duplicate`) / «Bul da Yurfak» (`also`) с `landmark.id` |
| `409` без `landmark` | звонок уже не ваш (бронь истекла и его взял другой) | взять следующий |
| `422` | нет имени / кириллица / неизвестный `landmark_id` | показать ошибку у поля |

Повтор того же решения после таймаута безопасен — ответит `200`.

## 4. Исправить опечатку — `PATCH /calls/landmarks/{id}`

`{ "name": "Yurfak" }` → `200 { "data": Landmark }`. `422`, если такое имя уже занято другим
ориентиром. Удобно на странице словаря (карандаш рядом с названием).

## Экран

```
┌──────────────────────────────────────────────────────────────┐
│  Qalǵan: 9 431   ·   Sózlikte: 127 orientir                  │
├──────────────────────────────────────────────────────────────┤
│  call-000123.mp3 · 0:11      [▶ Oynatıw]  ▁▃▅▇▅▃▁▃▅▇▅▃       │
│  «Assalawma áleykum, Yurfakqa mashına kerek…»                 │
├──────────────────────────────────────────────────────────────┤
│  Orientir: [ Yu▌                                    ]         │
│            ┌──────────────────────────────┐                   │
│            │ Yunusabad        (3 ret)     │ ← уже есть        │
│            │ Yurfak           (17 ret)    │                   │
│            └──────────────────────────────┘                   │
│  [ Saqlaw ]  [ Ótkerip jiberiw ]  [ Bul da … ]  [ Orientir joq ] │
└──────────────────────────────────────────────────────────────┘
```

Поведение:

- Аудио запускается само при загрузке звонка (если браузер разрешит) — экономит клик.
- **Набрал новое слово** → `Enter` / «Saqlaw» → `primary`.
- **Выбрал подсказку** (клик или `↓` + `Enter`) → по умолчанию **пропустить** (`duplicate`),
  отдельная кнопка/`Shift+Enter` — «Bul da …» (`also`).
- Если набранное **точно совпадает** с подсказкой (без учёта регистра) — не давать «Saqlaw», а
  сразу предложить пропуск: иначе бэкенд всё равно ответит `409`.
- «Orientir joq» — `Esc` или отдельная кнопка.
- Рядом с подсказкой — `mentions_count` («17 ret»): видно, насколько ориентир частый.
- После решения — сразу следующий звонок, без подтверждений.

## Критерии приёмки

- [ ] Пункт меню виден админу и супер-админу, не виден обрезчику.
- [ ] Перезагрузка страницы возвращает тот же звонок; два админа получают разные звонки.
- [ ] Новый ориентир создаётся; повтор того же слова в другом регистре → предложение пропустить.
- [ ] Подсказки появляются с первой буквы, сначала начинающиеся с набранного.
- [ ] Каждое из четырёх решений убирает звонок из очереди и сразу даёт следующий.
- [ ] Счётчики `remaining` / `landmarks_total` обновляются после каждого решения.
