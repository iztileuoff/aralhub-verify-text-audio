# Ориентиры в звонках — контракт с фронтом (27.10.2026)

> Согласовано с фронтом: за основу взят их документ («Новый раздел админки: ориентиры звонков»),
> бэкенд сделан по нему; отличия и ответы — ниже. Фронт: страница `/admin/landmarks`,
> пункт меню «Oriyentirler» у admin/super-admin.

## Зачем

Собрать **все ориентиры** (места, о которых говорят звонящие: «юрфак», «флаг»…) в тех же
≈ 10 000 звонках. Админ слушает звонки по одному и пишет короткий ориентир. Если такой уже есть —
фронт подсказывает, и админ нажимает «Пропустить»: звонок привязывается к существующему ориентиру.
Итог — полный список уникальных ориентиров с частотой (`calls_count`).

**С обрезкой не связано:** своя очередь и свой статус у звонка; на `calls/*`, роль Trimmer и
модерацию не влияет. Звонок может быть одновременно в работе у обрезчика и у админа ориентиров.
В очередь **не** попадают только звонки, которые обрезчик пометил непригодными (`skipped`).

- Доступ: admin и super-admin (роли 1, 2); остальным `403`.
- У звонка **один** ориентир (или «ориентира нет»). Выдача — **случайная**, бронь 30 минут.

## Статус звонка `landmark_status`

| Значение | Смысл |
|----------|-------|
| `pending` | ещё не слушали |
| `in_progress` | выдан админу, бронь (30 мин) |
| `labeled` | админ создал **новый** ориентир этим звонком |
| `duplicate` | ориентир уже был — звонок привязан к существующему |
| `empty` | ориентира нет |

Приходит в объекте `Call` **только админам**, вместе с `landmark: {id, name} | null`.

## Нормализация имени

`trim` → пробелы в один → нижний регистр → `ё`→`е`, `Í`/`í`→`ı` → пунктуация по краям убирается.
«Юрфак», « юрфак », «ЮРФАК.» — один ориентир (уникальный индекс по нормализованному имени).
Алфавит не ограничен, длина 2–100. Кириллица и латиница **не** сравниваются: `юрфак` ≠ `yurfak`.

## Эндпоинты

Base URL `https://api.verify.aralhub.uz/api/v1/admin`.

### 1. `GET /landmarks/calls/current`

Звонок, который админ уже держит, иначе бронирует случайный `pending`. Повторный запрос бронь
не продлевает. **`200`** `{ "data": Call }` (`landmark_status: "in_progress"`) или `{ "data": null }`.
Если `source_url` протух — запросить заново. В `Call` также `transcript` / `trimmed_url`, если
звонок уже обрезан (иначе `null`).

### 2. `GET /landmarks?search=юрф&per_page=8&page=1`

- `search` — подстрока по нормализованному имени; точное совпадение первым, затем `calls_count`
  убыв., затем по алфавиту.
- Без `search` — все, новые первыми.
- Пагинация Laravel. Элемент:

```json
{ "id": 12, "name": "юрфак", "calls_count": 37, "primary_call_id": 4810,
  "created_by": { "id": 1, "first_name": "Admin", "last_name": "A" },
  "created_at": "2026-10-27T10:12:00+00:00" }
```

`calls_count` — звонков привязано (`labeled` + `duplicate`); `primary_call_id` — звонок, которым создан.

### 3. `POST /landmarks/calls/{id}/label` — `{ "name": "юрфак" }`

Новый ориентир, звонок → `labeled`. **`200`** `{ "data": Call }`.
**`409`** `{ "message": "Этот ориентир уже есть.", "landmark": {id, name, calls_count, …} }` — такое
имя уже есть, звонок не меняется. **`422`** — имя пустое/короче 2/длиннее 100.

### 4. `POST /landmarks/calls/{id}/duplicate` — `{ "landmark_id": 12 }`

Звонок → `duplicate`, привязан к ориентиру. **`200`** `{ "data": Call }`; **`422`** — нет такого ориентира.

### 5. `POST /landmarks/calls/{id}/empty`

Без тела. Звонок → `empty`. **`200`** `{ "data": Call }`.

**Для 3–5:** `409` без `landmark` — звонок уже у другого админа (бронь истекла и его взяли) или уже
размечен; `422` с `message` — звонок не в работе у этого админа. Повтор того же действия тем же
админом — `200`.

### 6. `GET /landmarks/stats`

```json
{ "data": { "calls_total": 9989, "pending": 9120, "in_progress": 2,
            "labeled": 140, "duplicate": 690, "empty": 48, "landmarks_total": 140 } }
```

`calls_total` = сумма статусов (звонки без `skipped`).

### 7. `PATCH /landmarks/{id}` — `{ "name": "Юрфак" }`

Исправить опечатку. **`200`** `{ "data": <ориентир> }`; **`422`** — такое имя уже у другого ориентира.
